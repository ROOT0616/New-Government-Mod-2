# NGM2 効果消失・互換性精査（2026-10-23）

対象は原版 d54857bc、友人Workshop版、開発版 1.39.0-dev.16。実装基準はインストール済み Stellaris Cygnus 4.5.2 (9776)。オンラインでの最新配信版との一致は今回の調査対象外。

## dev.17での追記・訂正

技術取引・艦隊贈与は別MODへ分離済みとのユーザー指示により、NGMから入口法令・専用翻訳を削除した。以下のA01はdev.16時点の記録であり、現在は意図的除外。A03も再調査で、現行Vanillaに国家modifierからpop_resettlement_cost_multを使う実例があることを確認した。「置換誤り確認」は撤回し、効果の同等性未確認へ訂正する。詳細はhostile-traditions-audit.md参照。

## 結論

追加の問題はある。現在の開発版は「一部を復旧した開発途中」であり、原版の全機能復活・全効果保証が完了した状態ではない。特に、表示・選択の入口が残る一方で本体が欠ける機能、存在するキーを異なるscopeのキーに置換した箇所、種族特性に国家向け補正が残る箇所を優先して直す必要がある。

既存の構文検査の合格は、効果が実際に発動することの保証にはならない。今回、本体を変更せず、欠落・仕様差・要実機確認を整理した。以下の「確認済み」はコード上の事実を指し、ゲーム内で観測したことを意味しない。

## 未復旧の原版機能と残存参照

単に「ファイルがない数」をバグ数にはしない。旧Vanillaのoverrideを除去して現行Vanillaへ戻したもの、原版時点で入口が無効だったものも含まれるためである。今回の探索は現行Vanillaの定義名・イベントIDを除外して再集計した。

* 独自国是4件：`civic_ngm_freedom_in_obedience`、`civic_ngm_multiculturalism`、`civic_ngm_respect_act`、原版IDの `civic_ngm_space_security_headquarters`。友人版の末尾2付き国是は別IDであり、同一機能の保証にはならない。
* 起源6件：buffer_state、crime、escape_to_the_past、military、phenix、phenix_npc。
* 独自連邦4種類が未復旧。連邦パーク定義が残っていても、その連邦自体を作れることにはならない。
* AP7件、伝統定義77件、伝統カテゴリ7件、建物35件、区域7件などが不在候補。全IDは機械資料に記録。
* 不在候補への残存参照は736使用だが、固有名では44件・13ファイル。うち672使用は同じ伝統イベントファイル内の反復参照。736個の別個の不具合ではない。
* 例：拡大する偏執の議題、記憶の法令、記録方式の政策は不在伝統を前提とする。フェニックスの開戦事由・戦争目標・国作成処理も不在起源を参照。国是のない評議員3種も残る。
* `NOT = { has_ascension_perk = 不在ID }` のような否定条件は、単に到達不能になるとは限らない。保護・除外条件の欠落として別途評価が必要。

前回のcompatibility-audit.jsonにある不在イベント193件は、今回の現行Vanilla照合で150件の不在候補へ絞られた。この150件も発火経路のない原版イベントを含むため「150機能が壊れている」という意味ではない。

## 誤って「効果消失」と数えなかったもの

* 職業のplanet/country modifierをtriggered形式に移した箇所。構造上の移動であり、それだけで削除とはいえない。
* `leader_age` → `leader_lifespan_add`、住宅・快適度と人口単位の変換など、現行方式への変更。ただし最終値は要実機確認。
* 原版のコメントと実数値の不一致。繁栄1825日、宣教の精神主義誘引40%、礼典職の勲章0.2などは、コメントだけを根拠に現行を弱化・強化と判定しない。
* 社会主義の奴隷禁止タグは表示だけだが、政策側に社会主義禁止条件が実在する。タグしか見ずに「禁止が消えた」と判定しない。生活水準の4種拡張も実条件が存在する。
* 古いVanilla政体・生活水準を現行ベースへ戻した差分。原版固有の狙いと旧Vanilla標準を分離する。

## 検査の範囲と限界

原版・友人版・開発版を構文解析し、定義、全script内のイベント直接呼出し、不在原版定義への参照、modifier重複、種族特性のscope候補を抽出した。modifier部分の旧値・友人値・開発値差分もCSVに保存した。CSVの976行は移動・改名・AI weight変更等を含む「差分候補」であり、976件の効果消失ではない。同じ階層の繰返しブロックも集約するため、厳密な実行差分の代用にはならない。

既存のportable検査は再実行し、108ファイル・129イベントで合格した。しかし同検査の参照確認は主にon_actionであり、法令などからの欠落イベントを捕捉しなかった。一部の段階別テストは次段階前バックアップを検査しているため、最終統合状態の完全検査でもない。今回の指摘はその検査の不足を示す。

未実施：NGMを有効にしたLauncher起動、新規ゲーム、NGM専用error.log、イベントUI、実際の産出・人口・職業数、AIの選択、セーブ/ロード。参照した既存ログは別MODの実行記録であり、NGMの動作証明には使っていない。全DLC構成・他MOD併用・GUI全画面の互換性も保証していない。動的event IDや未知の独自外部依存を完全解決した静的解析ではない。

## 修正順序と確認方法

1. 壊れた入口と連携を修復：A01/A02/A07。方針として停止も可能だが、入口を黙って残す状態を解消する。伝統カテゴリ、採用、個別、完成、関連政策/法令を一括で追う。
2. 効果の適用先を修正：A03/A04/A05。再定住費用と研究・奴隷・家畜の効果を優先し、原版の利益・不利益を機能別に再現する。登録名があるだけで完了にしない。
3. 今回導入した仕様差を整理：青年研究速度、狂気特性の上位化、年齢対象、Crowdsourcing、統治職と交易の計算。
4. 原版由来の符号・重複・説明不一致を直す。原版の誤実装を仕様として固定しない。
