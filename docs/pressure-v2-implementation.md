# 対外圧力v2 実装記録 — 1.39.0-dev.18

対象：インストール済みStellaris Cygnus 4.5.2 (9776)。2026-10-23。

## 実装した内容

7種類の対外圧力を、受け手が発生国数を集計する処理へ置換した。同じ種類は国ごとに加算し、MOD独自の8/15国枠や加算上限を廃止。補正は種類ごとの1定義に人数分のmultiplierを渡す。狙い撃ち3か国は犯罪+90となる計算であり、engine側の表示・計算上限とは区別する。

| 種類 | 1発生国分 |
|---|---|
| 狙い撃ち | 犯罪+30 |
| 浸透 | 犯罪+20 |
| 破壊工作 | 犯罪+20、職業交易産出-15% |
| 報道の自由 | 奴隷幸福度-20パーセントポイント |
| 恒常的妨害 | 職業交易産出-5% |
| 敵対的演説 | 外交発言力-10% |
| 恒常的敵対諜報活動 | 基礎影響力産出-1/月 |

狙い撃ちと破壊工作は正式宿敵・架空宿敵、浸透は接触済み他国、それ以外は正式宿敵が対象。正式宿敵の方向は発生元から対象へのhas_rival。浸透は原版に合わせ同盟国・従属国も含む。正式宿敵と架空宿敵が同じ国でも、その発生元は1回だけ数える。

交易保護低下は現行で実在確認できないため、設計案どおり職業交易産出低下へ変更した。同等移植ではない。恒常的妨害の友人版の暗号化+5は外した。%補正は通常の加算で、各発生国分を乗算する方式ではない。

## 入口・更新・解除

悪徳と敵視の14伝統、および防御AP・社会秩序維持局を復旧。前衛・記憶など未対応の伝統は今回まとめて戻していない。

global on_game_start/on_monthly_pulseとcountry scopeのon_tradition_picked/on_ascension_perk_pickedから更新。取得時の旧on_enabledイベントを外し、二重更新を避けた。架空宿敵の追加・解除でも更新する。

発生源・対象関係・免疫から毎回再計算し、条件を失った補正は除去。免疫取得時は7種類を0へ。正式宿敵の変更・国家滅亡等は次の月次まで遅延し得る。新しい未確認フックは作っていない。

## 架空宿敵の画面

既存の追加・解除法令を再利用し、1ページ8候補の選択画面へ置換。次/前ページ、選択済みの除外、接触・採用条件の再確認を実装。固定世界枠を使わず、発生国から対象国へのrelation flagで保存する。ページの一時的な対象はローカルevent targetであり、共有global targetではない。

正式な外交上の宿敵を追加する処理ではない。選択画面は人間向けという元の条件を維持する。AIの正式宿敵による対外圧力には人間と同じ計算を使う。

## 旧save移行

旧63補正は空の互換定義として保持し、全countryから移行時に除去。playable国については継続的にも清掃する。旧発火・月次イベントはno-op互換IDとして残し、旧writerを止めた。無関係なmodifierや他MODのglobal flag/targetは一括削除しない。

旧架空宿敵は共有保存先の上書きにより元の意思を復元できないため自動変換しない。旧選択flagを持つ人間には再選択通知を一度出し、その国の旧選択flagと旧数変数をリセットする。旧global保存先は新処理から読まない。

## 同時に直した支援効果

- 国家宣伝省：宿敵数×自国影響力+1、上限+5。0宿敵と伝統喪失で解除。説明の「宿敵へ影響力」を訂正。
- 善隣完成：正しい完成伝統と5種族条件で判定し、不成立・領有変更・完成伝統不所持では解除。成長・職業交易・職業統合力+10%を維持。未確認の旧移民誘引補正は停止し、説明から除去。
- 宗主・従属国：7補正を現在の宗主の伝統/APと免疫条件で同期。領域継承が文化大臣の補正を付ける誤り、独立・宗主条件喪失時の残留を修正。旧清掃が無関係な宣教効果を消す処理は廃止。
- 超然的敵対存在：敵視の復旧で使えるようになる布告が有料・無効果だったため、有効中の宿敵上限+1を追加。原版の実装をそのまま戻したものではなく、明示的な不具合修正・効果追加。

## Override・競合・互換性

今回の新規Vanilla overrideはなし。既存のNGM独自定義と新規NGM接頭辞を使う。既に開発版が持つ政体・生活水準・GUI等のoverrideはそのまま残る。NGMの同じ伝統/AP/法令/イベントを変更する別MODとは競合し得る。

技術取引・艦隊贈与は別MODへ分離済みのまま維持し、復活させていない。Steam Workshopフォルダ、本体、sourcesは変更していない。

save互換性：移行処理あり。ただし実機未確認のため安全性は未保証。新規ゲーム推奨。旧架空宿敵は再選択が必要。移行前saveを保持する。旧版へ戻す場合も移行前saveを使う。
