# 旧補正・種族特性の現行化 — 1.39.0-dev.19

対象：インストール済みStellaris Cygnus 4.5.2 (9776)。2026-10-23。未検証の開発版。

## 変更の概要

従来の未登録補正候補67使用を、現在のVanilla実ファイル・engine出力文書に基づいて移植または再設計した。内訳は一般定義55使用（重複1使用の除去を含む）と種族特性の移民4・家畜8使用。種族特性ではさらに、生産・国家効果・艦船効果等を現行方式と適切な対象へ整理した。

全124種族特性のID、特性ポイント、相反条件、種族制限等を保持。95特性のmodifier等を変更し、青年政治の研究速度も復旧した。原版で不在の特性や他機能を一括復活させた作業ではない。

## 一般補正の対応

| 元の効果 | 改修後 | 仕様差 |
|---|---|---|
| 奴隷生産 | pop_slave_bonus_workforce_mult | 現行Vanilla奴隷ギルドと同じ追加労働力方式。率は保持。 |
| 交易保護+X | 国全体の交易産出+X% | 旧交易路保護の同等移植ではなく再設計。+5→+5%、+20→+20%。 |
| 艦船の海賊抑制+5 | 艦船維持費-5% | 巡回艦隊を維持しやすくする効果へ変更。 |
| 海賊法の旧抑制-30% | 艦船維持費-10% | 旧符号・仕組みを引き継がず警備負担を軽減する再設計。 |
| 移民誘引 | 失業者の自動再定住先としての魅力 | 旧人口流入・移民成長とは別の仕組み。率は保持。 |
| 移出圧力・移民成長（国家） | 失業者の自動再定住速度 | 自動移動へ再設計。すべてのPOPの成長率には変換しない。 |
| 旧降格時間 | 失業者の自動再定住速度 | 右材適所・平等は+50%、共産主義は+100%、カーストは-50%。旧+500%の時間を-500%の速度へ機械変換しない。 |
| 司祭職+3 | 行政官職の容量+300 | 現行の司祭は行政官職の表示・機能切替。通常の3職分を現行人口単位へ換算。 |
| 司祭/行政職の統合力+1 | 行政官カテゴリの統合力+1 | 表示上の司祭を含む現行行政職カテゴリへ。 |
| 兵士の犯罪産出-5/+1 | 兵士による安定度+5/-1 | 現行戒厳令で使うjob_soldier_stability_addを使用。犯罪低下そのものとは異なる。 |
| ロボット生産 | robotic_pop_bonus_workforce_mult | 現行の機械POP向け追加労働力。 |
| 文化職の生産 | pop_culture_worker_bonus_workforce_mult | 当該職業の追加労働力。 |
| 精神主義魅力 | pop_ethic_spiritualist_attraction_mult | 0.1は+10%。信仰の守護者の30は+30%へ正規化。3000%を維持したものではない。 |
| 使節由来の外交発言力 | 外交発言力+20% | 使節限定の旧補正が確認できないため国家の発言力へ再設計。 |

絶対的階級APに重複していた奴隷補正+15%は、1回分の+15%として整理した。+30%として保持していない。置換先と既存キーが重なる場合は加算して単一キーに統合し、同じキーの二重記述を避けた。国是・政策・議題・連邦等の条件と他の効果は維持した。

## 種族特性の生産・個体効果

現行Vanillaの農業・鉱業・発電・研究・伝統的・商才・魅力等と同じ職業別追加労働力aliasを使用。根拠はcommon/static_modifiers/24_static_modifiers_jobs.txtと現行species trait定義。名前を推測で作ったaliasではない。

- 生産資源別の旧planet_jobs補正は、対応する職業の追加労働力へ移植。全生産はpop_bonus_workforce_multへ。
- 物理・社会・工学の3率が等しい場合は全研究職のaliasへまとめ、同じ仕事を3回増やさない。
- NGM独自の複数資源産出職も生成されるpop_<job>_bonus_workforce_multで対象に含める。複数の対象資源がある仕事は元の率の平均を採用し、一つの仕事へ資源数分の補正を累積しない。これは資源別の独立した倍率と完全同等ではない。
- 快適度特性は現行の対人・快適度関連職の追加労働力へ。惑星全体の倍率として扱わない。
- 犯罪率の個体特性は、その種族の幸福度へ再設計（旧率×-0.5）。自種族の幸福・不満を通じて犯罪に影響する仕組みとし、少数種族一つで惑星全体へ犯罪倍率を配らない。
- 種族の移民成長は再定住費用へ符号を反転して移植。土地への執着は合計+35%、移動好きは合計-35%。居住性の利益・不利益は保持。
- 家畜食料の加減算は通常家畜の基礎食料4を基準に追加労働力へ換算。巨大は+75%（4→7）、大柄+25%（4→5）、小柄-25%（4→3）、極小-75%（4→1）、美味+50%（4→6）等。岩石家畜の鉱物へ無断で広げない。他の倍率との合算後に必ず同じ最終値となる保証はない。
- 個体数由来の帝国規模はspecies_empire_size_multへ。事務作業-5%、制御不能・禁止回路+10%など、保有国全体でなくその種族だけへ適用。
- 旧leader_skill_levelsは種族由来のリーダー経験値へ再設計（1段階を10%）。既存の経験値補正と合算。最大レベル上限を操作するものではない。
- 旧assembling_modifierブロックは除去。組立維持費の率は符号反転・半分の組立速度へ再設計（+30%維持費→-15%組立速度、-30%→+15%）。元から組立速度だった-5/-10%は率を維持して通常のtrait modifierへ移した。

寿命・種族由来経験値・軍隊など、現行で種族から適用する根拠のある効果は、engineのCategory表示だけを理由に削除していない。

## 国家・艦船向け効果

16特性に対応する国家補正を追加。該当traitを持つのが支配種族である間だけ、国家へ一度適用する。移民・少数種族の数では重複させない。

対象は飛行、透視、第六感、鈍重、退化、複雑/単純な遺伝、レンズ、ジェット、量子/霊子頭脳、不快、人工皮膚、戦闘CPU、軽量機械、青年政治に由来する該当効果。研究速度・改変費用・信用上限・関係改善・回避率・武器関連などを、種族のmodifierから国家側へ分離した。

支配種族変更・特性除去で次の月次に旧補正を清掃し、新条件を満たすものだけ再適用。ゲーム開始と月次のcountryフックを使用。特性の国家/艦船効果が少数種族でも発生する仕様ではないことを、日英の特性説明へ明記した。利益だけでなく研究速度低下・回避低下等の不利益も同じ条件で適用。

青年政治の失われていた研究速度+10%を復旧した。ただし、支配種族に特性があり青年政治国是が有効な間に限定し、国是を失って特性だけ残った状態から研究速度を得ない。

## 変更ファイル・override

既存のNGMのAP・議題・連邦パーク・国是・評議員・政策・静的補正・伝統・種族特性を変更。新規ファイルは以下。

- common/static_modifiers/NGM_species_country_modifiers.txt
- common/scripted_effects/NGM_species_country_effects.txt
- common/on_actions/NGM_species_country_on_actions.txt
- events/NGM_species_country_events.txt
- localisation/NGM_modern_traits_l_japanese.yml
- localisation/NGM_modern_traits_l_english.yml

descriptor、Launcher用.mod、README、CHANGELOGをdev.19へ統一。

新たなVanilla overrideは追加していない。ただし既存の00_policies.txt上書き内のdiplomatic_stanceのNGM補正を変更した。既存の政策全体のVanilla追随や他の旧overrideの互換性まで保証するものではない。これらや同名NGM定義を変更する他MODとは競合し得る。

## 検証と監査の読み方

- 119スクリプト/UI・135イベントの構文/参照/BOM検査が通過。
- 種族124定義のID・ポイント・相反条件・許可条件等を照合。旧一般定義の変更対象外データが保存されていることを検査。
- 家畜の基準換算、再定住費用、帝国規模の適用先、重複AP、司祭容量、精神主義30%の単位を検査。
- 実ASTの限定評価で支配種族の切替、少数種族の非重複、100回更新での非累積、利益・不利益の解除、有効国是条件、無関係な補正の保持を検査。
- dev.18の対外圧力の20条件と選択/移行/支援効果の53項目も再確認。
- 友人Workshop版922ファイルは未変更。

静的な未解決modifier候補は0、種族特性へ直接置かれた国家向け補正候補も0。判定にはengine出力だけでなく、実在するVanillaの職業補正aliasと宣言済み独自職業から生成される補正を含めた。根拠のない名前を一括で無視して0にしたものではない。生成補正がNGMロード時に登録されること、国→Pop/Colony/艦船への伝播、実際の産出、画面表示を実機で確認したという意味でもない。

## Save compatibility・未確認事項

ID・特性ポイント・許可条件等は保持し、種族を作り直さない。既存saveでは特性の効果が読み替わり、新しい国家補正は次の月次までに適用される。ただし実機でsave移行を検証していないため、安全性は未保証。新規ゲーム推奨、既存saveは更新前バックアップを保持する。

研究速度等の国家効果は支配種族限定になり、少数種族へ同じ特性を付けてもその国家効果は得られない。労働力方式の出力・維持費・複数資源職の倍率は旧式と完全同等ではない。比率の強さ、AIの種族組立/職業選択、ゲーム内の生成modifier登録・scope伝播・旧save再読込は未確認。

原版全機能の復旧は未完了。今回対象外の欠落伝統・起源・建物・連邦等、自由完成の派閥影響力、戦争終了時の補正清掃等は別の課題として残る。次は4.5.2実機で産出・種族切替・月次・保存/再読込を確認し、実測に基づいてバランスを調整する。
