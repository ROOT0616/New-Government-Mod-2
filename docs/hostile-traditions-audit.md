# 対外デバフ伝統・関連効果の精査（2026-10-23）

対象：NGM原版 d54857bc、友人Workshop版、開発版1.39.0-dev.17。基準：インストール済みStellaris Cygnus 4.5.2 (9776)の実ファイルとengine出力文書。

## 結論と今回の変更

**対外デバフ伝統と対応する防御・更新・解除処理は、現状では正常動作すると判定できない。原版自体にも複数の論理不具合がある。原版をそのまま戻すだけでは直らない。**

ユーザー指示により、技術取引・艦隊贈与は別MODの担当機能としてNGMから除外した。入口の `common/edicts/GFT_campaigns.txt`、専用翻訳 `localisation/GFT_*.yml` 9ファイル、休止中のAI呼出しコメントを削除した。別MODのファイル、原版・友人版の参照資料、本体、sourcesは変更していない。GFTが戻っていないことを今後のNGM復旧漏れには数えない。

今回、伝統のゲーム処理は変更していない。以下は修正前の監査結果であり、「修正済み」一覧ではない。

## 重要な不具合の詳細

### 1. 世界共通の8枠／15枠が使い切られる

`has_global_flag` と `has_country_flag` のNORで空き番号を探し、永久global flagをセットする方式。報道の自由、狙い撃ち、破壊工作、恒常的妨害、敵対的演説、敵対諜報APは8枠、浸透は15枠。

報道の自由を9か国が取得する条件では、9か国目に割当がないことを実際のASTから再現した。関連flagの `remove_global_flag` は開発版の全scriptを検索してもない。取得国が滅亡しても番号が回収されず、長期プレイほど枠が不足する。月次イベントは国別flagが既にあることを前提とし、割当なしの国を救済しない。

浸透の取得処理を同じ国で再実行すると、既存の所有枠を先に再利用せず次の空き枠を取る。通常の伝統取得が毎月起きるわけではないため、主に旧save移行・再初期化・イベント手動実行時の危険として扱う。

### 2. 浸透の免疫・解除が不完全

`ngm_tradition.7/.8` は1～15の効果を付与・更新するが、.8冒頭の免疫国からの除去は1～8のみ。実際の処理に1～15を付与した状態で免疫を設定すると、9～15の7効果が残った。

また浸透には `days` がなく永久付与。更新対象の条件から外れても、すでに付いた効果を消す分岐がない。接触条件を失うという仮定の反例でも残存を確認したが、これは通常の外交操作で接触を失えることを示すものではない。確実に考慮すべき失効経路は発生源の滅亡・伝統喪失・移行処理であり、それらの専用清掃もない。

30日型の宿敵デバフは、宿敵解除直後に消す処理がないが、期限で自然消滅できる。この点を永久残存と混同しない。免疫取得後も同様に即時解除ではなく期限待ちのものがある。

### 3. 架空宿敵は全体共有参照の設計にも問題

現在は選択用 `ngm_diplomatic.1/.2` が不在で通常利用できない。原版の選択処理も `save_global_event_target_as = ngm_virture_rival_country_1` のように国家ごとに名前を分けないglobal参照を使う。一方で利用側flagは国別。同じ番号を別の国が選ぶと共通参照先を上書きする設計である。

月次側にはevent targetの存在確認もない。死亡・対象消滅・古いsaveのflagだけ残存という条件に対応していない。選択イベントを戻す場合は、関係する法令・政策・target保存・解除をまとめて直す必要がある。

### 4. 恒常的妨害の説明と実処理が分離

原版の対外交易保護低下は友人版で暗号化+5に変更済み。今の定義には `on_enabled` がなく、初期割当flagが作られない。旧flagのない新規ゲームで月次.1012だけ呼んでも効果は出ない。

加えて `local_trade_protection_add` は4.5.2のengine登録・MOD生成定義で実在確認できない。旧処理を再接続するだけでは、交易保護低下の復旧完了にならない。効果を現行のどの仕組みへ置換するか決める必要がある。今回これを勝手に別デバフへ変更してはいない。

### 5. 対応する防御APも未復旧、原版の初期化先も不適切

防御側の社会秩序維持局APが不在なので、通常のゲーム進行で免疫条件を満たせない。原版では同AP取得時に.25を呼ぶが、.25のtriggerは別の「恒常的敵対諜報活動AP」を要求する。免疫取得を契機とした全面解除にはなっていない。

従属国向け効果でも、初回付与に免疫条件があって月次更新にはない処理がある（.27/.28、.36/.37、.38/.39）。解除イベントとの実行順で再付与と解除が繰り返され得る。防御は「攻撃時に除外」だけでなく、既存効果の解除まで一貫させる必要がある。

### 6. 国家宣伝省・善隣完成の取り違え

国家宣伝省の月次.14は1～5の宿敵数に応じて補正を切り替えるが、0になった時のelse清掃がない。1国→0国の反例で影響力+1が残った。5超も明示的な上限処理がなく、境界動作を設計し直すべき箇所。

善隣の更新.16のtriggerは `tr_ngm_ministry_engagement`。善隣完成だけでは発火せず、逆に国家宣伝省だけで善隣完成の惑星ボーナスを得る。初回.15にも月次.16にも「5種族未満になったら除去」がない。これは原版・友人版・開発版で同じ誤りであり、今回の移植で初めて発生したものではない。

### 7. 宗主・従属国向けの対応効果も要修正

領域継承と文化大臣の月次.33はORで発火した後、文化大臣のmodifierだけを付与する。領域継承だけを持つ国が新たに従属国を得ると、領域継承でなく文化大臣分の忠誠度+1が付く。

独立・免疫時の清掃.29には、領域継承と余裕完成のmodifierがない。さらに独立国の宣教modifierも除去対象に入っているため、宣教による精神主義誘引が月次で消される。しかし宣教済みflagは別管理のため、消えた後も再対象化されない恐れがある。宗主交代時も、単にis_subjectのままでは旧宗主由来の効果を判別できない。

## ほかに再確認した点

* **自由完成の派閥影響力+20%**：`pop_factions_influence_produces_mult` が残るが、現行Vanilla派閥・NGM派閥に影響力産出は確認できない。登録キーが有効でも元の産出が0なら増加は0。統合力へ変更するか別の影響力源へ再設計するかが必要。他MODが派閥影響力を追加する場合は別。
* **逆境完成の戦争終了処理**：.1002のtriggerが開始時と同じ「戦争中かつ防衛側」。最後の戦争終了後の状態なら発火せず、補正を残す条件になる。`on_war_ended` 自体も主敗戦国・主勝戦国のscopeであり、全参加国への月次清掃が必要。フック時点での状態確定順は実機未確認。
* **軍警察の惑星安定度**：.18には軍隊数10未満での解除があり、数条件の逆分岐は存在する。ただし伝統不所持・所有権変更後の清掃は別問題で、同イベントは伝統所持者しか走らない。条件があるだけで完全な清掃とはいえない。
* **破壊工作・恒常的妨害以外の未登録キー**：前回の17種類84使用は残る。今回は未確認キーを推測で置換していない。
* **PopとColonyのmodifier**：国家から配下へ伝播できる種類もあるため、engineのCategory表示だけで国家modifierを無効と判断しない。種族から国家へ上向きに効くかという問題とは分ける。

## 前回の再定住費用補正の判定を訂正

前回A03を「置換誤り確認」としたのは断定が強すぎた。4.5.2 Vanillaの `common/governments/civics/00_civics.txt:99`、`02_gestalt_civics.txt:198`、`common/edicts/00_edicts.txt:34` でも、国家に付けるmodifier内に `pop_resettlement_cost_mult` がある。

従って「Pops分類だから国是・法令から使えない」という根拠は成立しない。旧 `country_resettlement_cost_mult` も登録されている事実は変わらないが、それだけで今回の置換が無効とも断定できない。**置換先の国家からの利用は現行Vanillaに実例あり、旧効果との細かな同等性は未検証**へ判定を修正する。今回、補正キーを旧式へ戻す変更はしていない。

## 検証方法と限界

* 37カテゴリ・231伝統の依存関係を一覧化。全scriptからNGM独自の不在参照も抽出した。参照使用数は重複を多く含み、不具合数ではない。
* 実ファイルを構文解析し、限定したtriggerとeffectのみを評価する条件テストで13反例を再現。未対応の構文は黙って真扱いせず例外にする。ゲームエンジン、時間経過、modifierの積み重なり、実際のUIやscope伝播を再現するものではない。
* 13件には、未復旧APを仮に取得したケースや、取得処理の再実行などの将来復旧・移行用の反例も含む。13件の通常操作による別々のバグという意味ではない。
* portable構文検査はdev.17の107ファイル・129イベントで合格。GFT専用ファイルとGFT呼出しの残存なしも確認。構文合格と伝統の正常動作は別である。
* NGMをロードした実機起動、NGM用error.log、複数国同時取得、宿敵解除、国家滅亡、防御AP取得、宗主交代、セーブ/ロードは未実施。実機未検証の箇所は動作確認済みとはしない。

## 修正の順序

1. 伝統ごとの対象・期間・重複上限・防御条件を確定し、固定8/15枠と共通global targetを解消する。発生源・受け手の両方から清掃できる設計にする。
2. 悪徳・敵対の未復旧定義を、入口・更新・防御・関連議題までまとめて復旧する。恒常的妨害は原版効果と友人版暗号化のどちらを採用するか、説明と実装を揃える。
3. 善隣条件、国家宣伝省0国、従属効果の取り違え・解除漏れ、派閥影響力など原版由来の不具合を修正する。
4. 1/8/9/15/16か国、免疫取得前後、国の滅亡・新生、宿敵解除、5→4種族、独立・宗主変更、保存・再読込を4.5.2実機で検証する。

## 変更・互換性

バージョンは1.39.0-dev.17。今回の新規Vanilla overrideはなし。削除対象はNGM独自GFT法令と翻訳のみで、別MODと同名キーが衝突する範囲を減らす。既存save内のglobal flagや他MODの状態を消す移行処理は入れていない。NGM復旧全体のsave互換性は引き続き未保証・新規ゲーム推奨。

資料：`hostile-tradition-counterexamples.json`、`tradition-dependency-audit.json`、`effect-loss-audit.json`。前回の精査報告はdev.16時点の記録として残し、再定住費用の判定とGFT分離の追記を行った。
