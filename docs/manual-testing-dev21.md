# NGM2 実機確認チェックリスト

対象: Stellaris Cygnus 4.5.2 (9776) / New Government Mod 2 1.39.0-dev.21。

これは実装済みの開発版をユーザーがゲーム内で確認するための一覧。構文検査・独自評価器の合格と、以下の実機合格は別。最初はP0だけを行い、問題がなければP1、最後にP2へ進む。

**国家再設計（志向と国是の再選択・専用GUI）はまだ設計とHTML見本のみ。現在のゲームではテスト対象外。** 前衛・記憶など未復旧の伝統や、別MOD化済みの技術取引・艦隊贈与も今回の合否対象にしない。旧saveの移行・掃除は終了している。

記録: `[ ] 未実施` / `[x] 合格` / 項目末尾に「NG: 内容」。状況を作れなかった項目は未実施のままにする。非対応DLCは「対象外」と記録する。

## 準備

- [ ] S01 本体が4.5.2 (9776)、MODがdev.21であることを確認する。別の本体版なら、その版として記録し4.5.2の合格扱いにしない。
- [ ] S02 dev.21 ZIPを新しい専用フォルダへ導入する。旧フォルダへ上書きして残骸を混ぜない。
- [ ] S03 専用プレイセットを作り、まずNGM dev.21だけで試す。原版・友人版・旧開発版を同時有効にしない。
- [ ] S04 新規ゲームを使う。普段のsaveは検証に流用しない。
- [ ] S05 開始直後、最初の月替わり後、1年後、改革/戦争の直前に別名saveを作る。
- [ ] S06 起動日時・本体版・MOD版・DLC・帝国構成をメモする。ログは今回の起動日時のものを確認する。

## P0: 最初に行う起動・開始・月次試験

まず通常帝国1つで十分。初回の目標はゲーム開始から月替わりを数回、save/loadまで。

- [ ] T01 LauncherでMODが認識され、新規ゲーム開始まで進める。起動停止・クラッシュがない。
- [ ] T02 国家作成の志向・国是・起源・種族特性が表示され、日本語のキー名そのものや文字化け、押せない位置のボタンがない。
- [ ] T03 志向はVanilla＋NGMの8軸を確認し、合計6ポイントで正常に作成できる。対立志向や通常/狂信の重複を選べない。
- [ ] T04 帝政・企業等で、NGM志向に伴う不適合が正しく表示される。例えば帝政と社会主義/功利主義、企業と社会主義を不正に組み合わせられない。
- [ ] T05 開始直後に、選んだ志向・国是・起源が維持され、意図しないイベント連打や国是消失がない。
- [ ] T06 首都の職業枠が負にならず、独自職業に資格のあるPopが就業できる。失業は就業資格や需要も確認して判断する。
- [ ] T07 月替わりを1回、さらに数回通して、職業枠・惑星特性・国家補正が毎月積み重ならない。
- [ ] T08 saveしてゲームを終了し、同じsaveを読み込む。志向・国是・職業枠・補正が保持され、その後の月替わりでも二重化しない。
- [ ] T09 `error.log` に、NGMのunknown trigger/effect/modifier、invalid scope、parser error、未定義event、繰り返す同じエラーがない。最初の該当エラーを保存する。
- [ ] T10 1年程度進めても、月替わりの停止、同じイベントの連打、エラーの継続増加がない。

T01〜T10に問題がある場合は、深いバランス試験より先にその問題を切り分ける。

## P1-A: 国家形態と基本画面

別のテスト帝国を作る。無理に一つの帝国へ全機能を詰め込まない。

- [ ] A01 通常帝国: NGM志向と通常国是で、開始・月替わり・save/loadを確認。
- [ ] A02 企業: 適合する志向と企業国是で、企業政体・職業・外交姿勢が維持される。
- [ ] A03 集合意識: ゲシュタルト志向のまま開始し、通常志向が勝手に付かず、集合向け職業・国是が維持される。
- [ ] A04 機械知性: ゲシュタルトの機械帝国として開始し、通常帝国や生物集合と混同されない。
- [ ] A05 個別機械帝国（対応DLC所持時）: 通常志向を選べ、機械種族という理由で集合向け国是・職業へ変わらない。
- [ ] A06 政策の選択肢と条件説明が表示される。NGM条件が無い政策も現行本体の選択肢を失っていない。
- [ ] A07 機械信仰等の関連国是を使った場合、AI権利・ロボット政策と伝統主義派閥の要求が国是の説明と一致する。
- [ ] A08 寛容系国是の難民政策、追加志向の奴隷制条件、爆撃方針の選択条件が説明どおり。条件を満たさない組合せを選べない。
- [ ] A09 NGM派閥が条件成立後に出現し、要求の達成・不達成で満足度が変化する。ゲーム開始直後に派閥が無いことだけではNGにしない。

## P1-B: 独自職業・経済・惑星の同期

- [ ] B01 独自統治者職を付与する国是を1つ採用し、首都段階に応じた職業が追加される。
- [ ] B02 同系の職業置換国是を複数採用し、独自職業は加算されるが政治家の減少が元の容量を超えない。
- [ ] B03 首都を改築すると、独自職業の数が段階に合わせて変化する。月替わりで増殖しない。
- [ ] B04 植民、新しい惑星の取得・譲渡、関連国是の廃止で、当該惑星の独自職業・特性・補正が現在の所有者に合わせて更新/解除される。
- [ ] B05 儀典局・研究/交易/軍事系の独自職業に、資格のあるPopが就き、説明どおりの資源を生産する。
- [ ] B06 勲章資源が表示され、式典理論I/IIの研究・儀典局・勲章収入がつながる。
- [ ] B07 刑罰/罰金国是で、犯罪0なら収入なし、犯罪が増えると段階に応じた交易が生まれる。
- [ ] B08 可能なら犯罪0、1、1超、49、50以上を比較。内部の基礎段階は切り上げ・上限50。最終的な収入には別補正が乗りうるため、惑星特性の基礎値と総収入を混同しない。
- [ ] B09 犯罪が同じまま月を進めても収入・惑星特性が増殖せず、犯罪低下・国是廃止・惑星譲渡で減る/消える。
- [ ] B10 実験的物質の国是で、対象惑星に供給があり、非対象になれば消える。国是の説明と対象範囲も確認する。
- [ ] B11 民兵/人口比例防衛軍が人口に応じて変わり、月次で無限増加しない。所有者変更で新しい所有者の国是に従う。

## P1-C: リーダー・若年/長老・種族

- [ ] C01 青年政治の初期/新規/候補リーダーが初回10〜20歳、長老政治では65〜100歳になる。以後は自然に年を取り、毎月年齢を再抽選しない。
- [ ] C02 青年/長老の特性・経験値等が月次やsave/loadで重複しない。
- [ ] C03 既にレベルが高いリーダーを、最低レベル保証の処理で低いレベルへ戻さない。
- [ ] C04 徒弟国是で、初回のレベル/特性付与を確認し、月次で経験値・特性を無限取得しない。
- [ ] C05 根本的狂気で、対象科学者が未所持なら初段を取得、既存初段なら2段へ一度だけ昇格。既存2/3段を下げず、次の月次でさらに昇格しない。
- [ ] C06 外部雇用者・イベント由来リーダーも試し、意図しない表示・年齢・特性の組合せがないか記録。現実装は原版寄りの広い適用範囲を維持している。
- [ ] C07 若年/長老の主種族改変で、自国の対応Pop・リーダー等が整合する。外国の同種族を巻き込んで変更しない。
- [ ] C08 若年/長老の国是を失っても、既に付いた種族特性・贈与特性は残る仕様を確認する。若年の条件付き国家研究補正は、国是無効化後に解除される。
- [ ] C09 少数種族だけに国家/艦船効果付き特性がある場合、国家全体へ効果が付かない。
- [ ] C10 同特性が支配種族にある場合は国家効果が一度だけ付き、支配種族・該当特性が変わると次の月次までに解除/更新される。

## P1-D: 戦争・繁栄

- [ ] D01 戦争経済の国是で、開戦後に戦時、平時に戻ると平時の補正になる。国家と惑星の両方を確認する。
- [ ] D02 二つの戦争の片方だけを終了しても、まだ戦争中なら戦時効果を維持する。
- [ ] D03 戦争経済の国是廃止、植民・惑星譲渡、save/load後にも正しい状態になる。
- [ ] D04 逆境完遂で、防衛戦争中だけ亜高速移動補正が付く。攻撃戦争だけでは付かない。
- [ ] D05 二つの防衛戦争の片方だけ終了しても維持し、最後の防衛戦争が終われば解除される。
- [ ] D06 逆境を勝者・敗者・同盟参加者それぞれで確認し、終了後に補正が残らない。
- [ ] D07 繁栄国是で、平和が1825日続いた後の月次に段階が進み、開戦すると蓄積がリセットされる。

一部の補正の整合修復は月次経路を持つ。操作直後と次の月替わり後を両方記録する。「次の月に直る」と「即時更新するはずなのに遅れる」は分けて報告する。

## P1-E: 対外デバフ・仮想宿敵・支援

最初は発信国1つ、次に同じ効果を持つ発信国を複数用意する。必要な状況を通常プレイで作れない項目は未実施として残す。

- [ ] E01 正式宿敵で対象になる伝統/APについて、発信国→受信国の正しい向きに効果が付く。受信国が一方的に宿敵指定しただけで逆向きに発生しない。
- [ ] E02 「浸透」は接触済みの他の対象国へ付く。正式宿敵以外の同盟・従属国も対象となる現在の仕様と一致する。
- [ ] E03 同じ効果を持つ2国・3国から受けると、その国数分が加算される。重複すること自体はバグではない。
- [ ] E04 同じ関係のまま数か月進めても、毎月さらに効果量が積み重ならない。
- [ ] E05 宿敵解除・発信国消滅・発信能力喪失で、該当する分だけ効果が減る/消える。
- [ ] E06 「社会秩序維持局」で対象デバフが解除される。免疫条件がなくなれば必要な分が再適用される。
- [ ] E07 悪徳の仮想宿敵メニューで追加・解除でき、ページ送り・戻る・中断で別の相手を誤選択しない。
- [ ] E08 正式宿敵と仮想宿敵の両方に同じ相手を指定しても、その同じ発信国から二重計上しない。
- [ ] E09 選択後に接触・資格等が変わった相手を、古い画面から不正に指定できない。解除後はその相手の効果だけが更新される。
- [ ] E10 国家宣伝省の自身の影響力は、正式宿敵数に応じて+1/国、最大5。宿敵0や伝統無効で解除。
- [ ] E11 善隣完遂の惑星効果が5種族以上で付き、4種族以下・所有者の資格喪失で解除される。
- [ ] E12 宗主由来の支援・圧力が、独立・宗主交代・免疫・宗主の資格喪失で解除/更新される。

- [ ] E14 save/load後も、仮想宿敵の選択とデバフ強度を保持する。古い番号付きデバフや旧移行通知が新規ゲームへ出現しない。

- [ ] F02 惑星・開発・工芸の伝統3系統について、採用・途中・完遂の効果と説明を確認する。元コードの数値の正負を残した箇所は、期待した強さかも記録する。
- [ ] F03 復旧した地上軍4種と評議会方針6件について、候補出現・条件・コスト・実際の効果を確認する。
- [ ] F04 種族特性の職業生産・追加労働力・幸福度・帝国規模・家畜・リーダー経験値等が、実際の該当種族/職業で機能する。

ユーザーデータのログ位置: `E:\ドキュメント\Paradox Interactive\Stellaris\logs\error.log` と `game.log`。NGM以外の以前のプレイのログと混ぜない。再起動で変わる場合があるため、不具合を確認した回のログを先に別名保存する。
