# 前衛完遂「国家再設計」設計 v1

2026-10-23 / 基準: インストール済みStellaris Cygnus 4.5.2 (9776)、NGM2 1.39.0-dev.21。

状態: 設計。ゲーム用MODへ未導入。専用GUIの接続・更新は実機試作が必要。付属HTMLは操作イメージであり、Stellarisで動くGUIではない。

## 1. 目的と範囲

前衛完遂で一度だけ得る権利を使い、国家の志向と国是を同じ変更案として組み直す。編集・中断中は実際の国家を変更せず、最後の確定でだけ適用する。

初版の設計判断:

- 国家の志向と国是を対象とする。政体は表示・適合検査のみで、変更しない。
- 非集合帝国は既存8軸の志向を編集し、NGMの6ポイントを使う。途中の不足・超過は許し、確定は規定点数・対立関係・政体等との適合を満たす場合だけ。
- 集合意識と非集合の相互転換、集合意識と機械知性間の転換は提供しない。集合帝国では志向を固定し、対応する国是だけ編集する。
- 個別機械帝国を「種族が機械だから集合」と扱わない。現在の国家・政体の分類で決める。
- Popの志向、種族、起源、領土、外交関係、研究を直接書き換えない。国家志向変更に伴う派閥・政策・職業・外交等の影響は表示・適合確認の対象。
- 実行権利は正常な適用完了時に一度だけ消費。画面を閉じる、中断、案を破棄、変更なしで終了した場合は消費しない。
- 政体変更や国家形態の転換は、必要なら別の拡張として扱う。

## 2. プレイヤーの操作

完遂通知 → 「国家再設計を開く」 → 志向を編集 → 国是を編集 → 問題を確認 → 最終確認 → 適用。

最初の編集案は現在の状態そのもの。「残す」を基本にし、削除や追加を明示する。編集中に現在の国是を先に消さない。

中断後は専用布告「国家再設計を再開」から同じ案を開く。入口は布告と完遂通知に限定し、初版では政府画面・上部バーを丸ごと上書きしてボタンを増やさない。

## 3. 専用GUI

推奨論理サイズ: 1120×700を上限の目標として中心配置。1280×720では高さを縮めた版、UI倍率を上げた場合は上下を分ける小型版を用意する。実際のピクセル値はゲーム内の文字サイズ・倍率で確定する。

```
┌ 国家再設計                         未確定の変更案 / 使用権利1 ┐
│ 志向 6/6    国是 使用/上限    政体: 現在の政体（固定）       │
├─────────────┬─────────────────────────┬───────────────────┤
│ 志向        │ 志向の8軸 / 国是候補一覧 │ 現在 → 変更後      │
│ 国是        │                         │                   │
│ 変更点      │ 分類 / 追加元 / 状態    │ 追加・削除         │
│ 問題        │                         │ 必要条件・注意点   │
│             │ 候補詳細・採用/解除     │                   │
├─────────────┴─────────────────────────┴───────────────────┤
│ 案を破棄       中断する                 確認へ進む           │
└───────────────────────────────────────────────────────────┘
```

### 志向

8軸を各1行で表示。各軸は「左の狂信 / 左の通常 / なし / 右の通常 / 右の狂信」の5状態。選択値は -2,-1,0,1,2。クリックでその軸を置き換えるので、左右同時採用や通常と狂信の二重採用は起きない。

Vanilla4軸: 権威↔平等、軍国↔平和、排他↔受容、精神↔物質。NGM4軸: 社会主義↔資本主義、介入↔中立、保全↔開発、名誉↔功利。表示名は実際のlocalizationを優先する。

消費点は各軸の絶対値の合計。国家作成画面で許されない組合せを勝手に緩和しない。狂信の追加制限が必要かは現行作成画面・定義との比較試験で確定し、未確認の「狂信は一つだけ」等を独自に追加しない。

選択すると、志向を前提とする国是の警告を即座に更新する。警告が出た国是を無断で削除せず、変更案に残して修正を促す。

### 国是

- 分類: すべて / 統治 / 経済 / 研究 / 軍事 / 社会・外交。
- 追加元: すべて / Vanilla / NGM。
- 状態: 採用可能 / すべて / 選択済み。条件不足の候補も内容を閲覧できる。
- 1ページ6件を基準に、名前・主な効果・採用状態を表示。前/次とページ位置を常設する。
- 候補の詳細では効果、志向・政体・DLC条件、組合せ競合、変更可能性を表示する。
- 自由入力検索、任意のドラッグ&ドロップ、動的なカード格子は初版の必須条件にしない。

国是枠は7固定にしない。現在のNGM基礎枠は7だが、技術・伝統・補正・国是自身による増減がある。予算は変更後の案を基準に計算する。未対応の枠補正・コストがあれば「計算できない」として確定を止め、勝手な数値で代用しない。

### 変更点・問題

現在と変更後を比較して、志向の強弱、追加/削除国是、政治体制との適合、関連する政策・種族権利・職業・評議員・外交の注意点を示す。効果の合計値は正確に計算できる項目だけ表示し、国家経済全体の予測値を捏造しない。

問題は「確定を妨げるもの」と「適用後に確認する注意」に分ける。例えば志向点超過、政体不適合、国是競合、未対応の特殊国是は停止条件。Popの既存志向と国家志向の違いは、それだけでは停止条件にしない。

最終確認には変更一覧と使用権利の消費を明記。「戻る」と「この変更を適用」を分離し、確定を通常の閉じる操作に割り当てない。

## 4. 現行エンジンでの専用GUI実装方針

### 確認できた土台

1. `events/astral_planes_events.txt` 等に `custom_gui` を指定するイベントが実在する。
2. `interface/diplomacy_curator_event_view.gui` に専用window、`option_list`、`option_button`、`action_title`、`action_desc`等のエンジン接続部品がある。
3. `common/button_effects/example.txt` にeffectbuttonTypeからscriptへ接続する現行の説明がある。Thisは選択中オブジェクトの場合があり、Fromはプレイヤー国。実例は `behemoth_effects.txt` と `interface/fleet_view.gui`。
4. `common/scripted_loc/000_example.txt` に条件付きテキストとscript valueの表示方法がある。

### 採用する構成

独自名のイベントGUIと選択肢テンプレートを作り、`custom_gui` / `custom_gui_option`で呼ぶ。国是候補はまずエンジンが扱えるイベント選択肢の縦一覧で表示する。独自の任意データモデルを作れるとは仮定しない。

余白・タブ・ヘッダー・色・詳細配置は独自レイアウトにする。8軸ボタンや常設操作はeffectbuttonTypeでの接続を試作し、画面の更新が成立するなら採用する。各ボタンは固定IDから登録済みの編集effectを呼び、任意の文字列を国是IDへ動的変換する方式にはしない。

表示更新が不安定なら、各操作を通常のイベント選択肢として処理し、古い画面を閉じて次の専用画面を開く方式に切り替える。開いたままイベントを重ねて無制限にwindowを増やさない。

国是固有アイコンは既存textureの実在確認後に生成したテンプレートへ割り当てる。取得できない場合は共通アイコンと文字で表示する。

### GUI試作の合否判定

最小試作は国是全件を作る前に行う。

- 独自名のwindowとoptionテンプレートが実際に開く。
- 他帝国や惑星を選択した状態でも、操作先は開いた本人の国になる。画面scopeに依存して他オブジェクトへflagを置かない。
- 志向1軸の変更で国別の仮選択値と表示が更新される。
- 国是2件の仮選択と解除を表示できる。
- 中断・再開・閉じる・Esc・セーブ/ロードで実国家は変わらず、案は残る。
- 他プレイヤーの編集案を変更できない。
- 1280×720、1920×1080、UI倍率変更、日本語の長い名前で操作できる。

この試作に合格するまでは、レイアウト図どおりの三列画面やリアルタイム更新を「実装済み・実現確認済み」としない。付属HTMLの自由入力検索等のWeb固有機能を、そのままゲームで可能とは扱わない。

## 5. データと内部処理

ゲーム用prefixは `ngm_redesign_`、イベントnamespaceは `ngm_redesign`。既存NGMの他機能と混同しない。

管理状態: available → editing → review → applying → consumed。中断はediting/reviewの案を保持したままUIだけ閉じる。破棄は案を削除してavailableへ戻す。

国ごとに保持するもの:

- 一度限りの権利、編集開始済み、適用中、消費済み。
- 元の志向・国是・政体を表すsnapshot。登録外の所持国是があるかも記録。
- 8軸の編集値、選択国是のflag、表示分類・ページ・選択中の詳細ID。
- 編集版数と編集時点。review後に案が変わったら再確認を必須にする。

global flagや長期保持したglobal event targetは使用しない。国是・志向IDは登録表から固定scriptを生成する。UIからの操作は「本人の国」「権利あり」「適用中でない」「対象IDが登録済み」を再確認する。

既存NGM effectにはRootが国であることを前提にする処理がある。GUIボタンのThisが惑星・艦隊等である可能性を残したまま直接呼ばず、検証済みのプレイヤー国へcountry eventを送って国Rootを確立してから実行する。

## 6. 条件検査

実際の国はまだ変わっていないため、現在の `has_ethic` / `has_civic` をそのまま使うと変更案を正しく検査できない。検査は「案の志向」「案の国是」「現在の固定政体」「DLC・起源等の固定条件」を参照する。

Vanillaの `common/governments/99_README_GOVERNMENT.txt` は国是・政体のrequirementsが通常triggerと別書式であると説明している。対応する構文を明示して変換し、未対応構文を無条件許可しない。

登録表にはID、出典、分類、効果説明、アイコン、コスト、条件、競合、追加/削除ポリシー、特殊移行処理、対応状態を持たせる。表示条件・確定検査・テストを同じ登録表から生成する。AI weightそのものを選択合法性として使わない。

起源・種族・外交・専用システムの開始処理を伴う国是は「通常変更可能」「保持専用」「専用移行を実装したときだけ変更可能」に区分する。前衛による条件免除は登録表の明示的な例外だけにし、無制限force追加をしない。

他MODの未登録国是は保持専用にする。ただし志向変更後にも有効か判断できない場合がある。初版では登録外国是を所持している国の志向変更は停止し、国是だけの対応済み変更か、追加互換登録を案内する。存在を無視して安全と判定しない。

登録外の国家志向や通常と異なる志向点数ルールがある場合も、黙って削除・6点への切り詰めをせず、対応登録まで志向編集を停止する。

## 7. 志向・国是の適用

engine docsで `country_remove_ethic`、`country_add_ethic`、`force_remove_civic`、`force_add_civic`、`change_government`の実在を確認。完全な指定組合せを作る必要があるため、他の志向を自動調整する `shift_ethic` は主方式にしない。

適用は以下の順序を設計上の基準とする。

1. 権利、状態、本人、元の国家snapshot、変更案、政体適合、国是条件、最終枠数を再確認。
2. 実国家が編集中に変更されていたら停止。案を保持して再読込・調整を案内する。
3. 適用中flagを置き、同一国の二重確定を防ぐ。
4. 専用移行に対応する削除予定国是の終了処理を実行。
5. 変更対象の国是と国家志向だけを外し、指定した国家志向を追加する。
6. 選択国是を追加し、必要な開始処理を実行。
7. 政策・種族権利・派閥・評議員等の整合性を確認し、NGMの職業、戦争/繁栄、種族国家効果、対外圧力、リーダーの同期入口へ接続。
8. 実際の志向・国是が変更案と一致し、無効国是がないことを確認して権利を消費。編集状態を終了。

effectを同じ即時処理内で実行しても、engineが完全なtransactionやrollbackを保証するとは確認していない。途中状態が関連on_actionへ影響するかを試験する。全副作用を自動で巻き戻せると約束しない。想定外の結果では、消費済みにせず適用失敗状態で停止してログとsnapshotを保持し、実機検証用saveで原因を追う。

国是変更に伴う外部外交や専用システムを元に戻す必要がある候補は、事前に対応できたものだけ許可する。

## 8. 解禁・AI・互換性

現在は前衛のカテゴリ参照と旧メニューはあるが、完遂等の伝統定義が未復旧。実装時は依存する7伝統の復旧/条件を確認し、完遂の入口だけを孤立して追加しない。

完遂時は権利を付与して案内を表示するだけ。開いていない間の月次全走査は追加しない。編集操作・再開・確定時にだけ必要な検査を行う。

初版の前衛AI選択は現在の停止設定を維持する。AIへ解禁する段階では同じ条件検査・適用処理に専用の構成選択を接続する。プレイヤー向けGUIをAIへ開かない。

旧saveの移行・旧flag清掃は追加しない。開発版の既定方針に合わせて新規ゲームで検証する。既存saveへ安全に追加できると案内しない。

既存政府画面の上書きを増やさない。独自GUI名・ボタンeffect・localizationを使う。既存の倫理作成GUI等の競合範囲は別途残る。国是を追加する他MODは登録しない限り編集対象へ自動対応しない。

## 10. 実装順序と合格条件

1. GUI最小試作。独自window、本人scope、1軸、2国是、中断・再開。
2. 志向8軸の案・6点検査・集合帝国固定・政体適合。
3. 国是登録表と案の条件検査。未対応は停止。
4. 確認・確定・NGM同期。専用移行が必要な国是は別試験。
5. 前衛伝統との接続、全候補登録、日英表示、倍率・解像度調整。
6. 実機のセーブ/ロード、国家改革との競合、二重操作、マルチプレイヤー、長期挙動。

必須テスト: 編集中は実国家不変、左右志向排他、点数境界、NGM全軸、集合転換不可、政体不適合、国是競合、国是自身の枠増減、固定国是、登録外国是、編集中の外部変更、中断/破棄/再開、二重確定、適用失敗、国是解除時の補正、評議員、政策/権利、既存Pop志向の保持。
