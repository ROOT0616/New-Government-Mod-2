# New Government Mod 2 1.39.0-dev.18

対象：ローカルStellaris Cygnus v4.5.2 (9776)。原版1.38.30と友人版1.00からの復旧作業版です。全機能対応版・通常プレイ用の完成版ではありません。

## 復旧済みの主な範囲

- 追加倫理16定義、国家作成の倫理GUI、追加8派閥、現行19生活水準への条件。
- 勲章資源、式典理論I/II、儀典局。独自職業14種の現行化とNGM貴族。
- 原版で有効だった国是イベント23 ID。青年/老年政治、徒弟、狂気、繁栄、戦争経済、刑罰、物質発見、解剖、伝道、初期技術。
- 停止国是18件を今回復旧。以前の歴史ある勲章と合わせて19件。首都の専用統治者職50組合せ。
- 航空騎兵・砲兵・機甲・特殊作戦の地上軍4種、評議会方針6件。
- 起源7件：植民熱、玉座の上のバランサー、自由都市圏、名門、保守主義の権化、肥大化した行政権力、革命の寵児。
- 惑星・開発・工芸の伝統3系統21定義。人口比例防衛軍。

## 移植の相違

交易補正の一部は職業交易産出へ、旧人口成長はlogistic_growth_multへ移植。旧版との最終的な出力の一致は未確認です。人口・職業枠・快適度は現行の100単位へ変換しています。

繁栄は原版実コードの1825日・10段階を維持し、期限後の月次に更新。和平の勝者等の補正修復も月次になる場合があります。

青年/老年政治は主種族の改変種を作成し、自国の同種族のPOPグループ・リーダー等を移行します。初期/新規/候補リーダーの年齢を一度だけ青年10–20、老年65–100へ設定。国是効果と種族特性は併存し、国是を失っただけでは種族特性は消えません。外国の同種族は変更しません。

異種族解剖は現行Vanillaの奴隷化資格・政策条件を尊重します。実験的物質は原版実コード通り全領有惑星へ供給。刑罰収入は犯罪値切り上げ・最大50の交易を直接生産します。

専用統治者職は首都建造物を上書きせず惑星特性から供給。政治家の減少は首都の基本枠までに制限し、国是を重ねても負の枠を避けます。新規起源7件と伝統3系統には既存画像を仮使用しています。

現行エンジン資料で未登録の補正候補が67か所あります。動的生成の再確認が必要なものも含みます。対外圧力で使っていた旧交易路保護は新方式へ置換しましたが、他機能の旧交易路保護・人口移動などには未対応箇所が残ります。

115個のスクリプト/UI構造検査、既存機能の回帰検査、統治者職5120組合せ、刑罰・戦争・繁栄・人口比例防衛軍の検査を実施。実機の起動・GUI・実産出・AI・イベント・セーブ/ロード・性能は未検証です。

別プレイセット・新規ゲームから検証します。既存セーブへの安全性は未判定で、旧繁栄蓄積は引き継ぎません。通常プレイや既存セーブの置き換えには使わないでください。原版/友人版との同時有効化は同名定義が競合します。

## 対外圧力v2（dev.18）

7種類は発生国ごとに加算し、8/15枠を廃止。宿敵指定は発生国から受け手の方向で判定します。架空宿敵は法令から国別に選択・解除できます。正式な外交関係は変更しません。免疫AP取得で既存効果も解除。関係変化・滅亡等は次の月次に反映します。旧63補正は清掃し、旧架空宿敵は対象を安全に復元できないため再選択を通知します。

破壊工作・恒常的妨害の旧交易保護低下は、職業交易産出-15%/-5%へ変更。友人版の恒常的妨害の暗号化+5は廃止します。善隣の未確認移民誘引は停止し、残る成長・職業交易・統合力+10%を条件付き同期します。超然的敵対存在は元の有料・無効果状態を修正し、宿敵上限+1を付けました。

実機検証未完了、新規ゲーム推奨。実装状況はdocs/pressure-v2-implementation.mdを参照。

宗主・従属国由来の7補正も現在の宗主の伝統/APで同期し、独立・宗主交代・免疫で清掃します。旧清掃が無関係な宣教効果まで消す問題を修正しました。
